# アプリ6: 変更届 作成ツール（放デイ・児発） slug=henkou-todoke OWNER=放デイの書類屋さん（houday.jp）
目的: 放デイ・児発の管理者/事務が、指定内容の変更（管理者・児発管・従業員・運営規程・所在地など）が起きたときに、変更届出書を様式どおり作成し、提出期限（変更の日から10日以内）と添付書類を漏れなく管理する。
## ルール（app.jsで定数化・設定で変更可）
- 提出期限 = 変更年月日 + 10日（児童福祉法第21条の5の20。設定で日数変更可）。土日の場合は注意表示。
- 変更事項はさいたま市様式第3号の13項目。13「その他」は従業員の変更／主たる対象者／協力医療機関／定員／上記以外のサブ項目。
- 添付書類はさいたま市「変更届添付書類一覧（H30.4）」を基に項目×サービス種別（児発/放デイ/保育所等訪問/医療型）でマトリクス化。○=必ず添付、△=条件付き。複数項目で重複する書類は1行に統合（○が1つでもあれば○）。
- 特記の自動注意: 所在地変更（前月10日まで・事前相談）、給付費請求事項（体制届は前月15日まで）、児発管交代（減算リスク）、定員変更。
- 日付は和暦（令和）表示。設定で西暦に切替可。
## 画面
1. 一覧: KPI（期限超過／7日以内／未提出／今年度提出数）、変更届テーブル（事業所・変更事項・変更年月日・提出期限・状態pill・操作=編集/印刷/複製/削除）、フィルタ（事業所・状態）、添付書類早見表（13項目アコーディオン）。
2. 事業所モーダル: 法人名・主たる事務所所在地・代表者職名/氏名・事業所名・事業所番号10桁・所在地・支援の種類（チェック）・宛先・様式番号・申請事務担当者/TEL/FAX。複数事業所登録可。
3. 編集ビュー: 事業所選択・変更年月日・届出日・状態 → 提出期限を自動表示。変更事項チェック → 変更前/変更後テキスト（ひな形挿入ボタン）→ 添付書類チェックリスト（準備済みチェック）→ メモ → 保存/印刷。
4. 印刷: 様式第3号レイアウトの変更届出書（A4・明朝・事業所番号10マス・該当番号に○・変更前/変更後）＋2ページ目に添付書類チェックリスト（控え）。チェックリストのみ印刷も可。
5. 出力: JSONバックアップ/復元（全員）、提出台帳CSV（Pro）。
6. Free: 事業所1件・変更届3件まで。Pro（¥1,980買い切り）: 無制限＋提出台帳CSV。
7. .note: 様式・添付書類は自治体により異なる。宛先・様式番号は事業所ごとに設定可。
