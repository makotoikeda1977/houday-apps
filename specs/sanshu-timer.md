# アプリ5: 社労士 3周法タイマー（択一・選択式） slug=sanshu-timer OWNER=シャロッシング
目的: 社労士試験の受験生が「3周法」（1周目=全問を高速判定して L1確信/L2迷い/L3捨て に仕分け → 2周目=L2を解く → 3周目=L3と見直し）を本番同様の時間感覚で訓練する。ブランドは「シャロッシング」（YouTubeチャンネル）。
## 3周法の定義（app.jsに定数化）
- 択一式: 70問・210分。科目順と問数: 労基・安衛10 / 労災・徴収10 / 雇用・徴収10 / 労一・社一10 / 健保10 / 厚年10 / 国年10。
  1周目 60分（9秒ルール＝1問あたり判断は最大9秒×5肢≒45秒・迷ったら即L2/L3に送る）。科目チェックポイント（分）: 9 / 17 / 26 / 34 / 43 / 51 / 60。
  2周目 90分（L2を解く）、3周目 60分（L3＋見直し）。＝合計210分。周ごとの時間は設定で変更可。
- 選択式: 8科目×5空欄（労基安衛/労災/雇用/労一/社一/健保/厚年/国年）・80分。1周目（20分目安）=全科目を眺めて「危険科目（基準点割れリスク）」を特定して印を付ける、2周目（40分）=安全科目を確定、3周目（20分）=危険科目に残り時間を全投入。CP: 各科目2.5分（1周目）。
## 画面
1. モード選択: 択一式 / 選択式。開始前に周ごとの時間を編集可（Freeは既定値のみ、Proで編集）。
2. タイマー画面（本番の主画面・スマホで片手操作）:
   - 大きな残り時間（周の残り）、周番号（1/3など）、全体の経過時間。
   - 科目チェックポイントバー: 現在どの科目にいるべきか（経過時間からの目安）と、実際に自分がいる科目（タップで切替）を並べて表示。遅れていれば赤「-3分」、進んでいれば緑。
   - 問題グリッド: 択一は1〜70のボタン（科目ごとに区切って表示）。タップで状態を循環 未→L1→L2→L3→未。長押し(またはダブルタップ)で「済(解答済み)」マーク。選択式は科目×5空欄のグリッドで同様（状態は 未/安全/危険/済）。
   - 周の切替ボタン（「2周目へ」）。次の周では対象問（L2 or L3）が強調され、他はグレー。
   - CP到達・周の残り5分・終了時にビープ音（Web Audio APIで生成、外部音源禁止）＋バイブ（navigator.vibrate があれば）。音のON/OFF。
   - 一時停止/再開、中断（確認ダイアログ）。画面スリープ防止（Wake Lock API があれば使用、無ければ何もしない）。
3. 結果画面: 科目別に L1/L2/L3/済 の数、1周目の科目別所要時間（CP切替タイムスタンプから算出）、目標CPとの差、L3（捨て）が多い科目の警告、総所要時間。「今回のメモ」欄。
4. 履歴: セッション一覧（日付・モード・所要時間・L3数）、タップで結果再表示。Freeは直近3件、Proで無制限＋科目別の推移（L3数と1周目所要時間の簡易折れ線をCanvasで描画）。
5. 使い方カード（初回表示・後から開ける）: 3周法の説明を上記定義から簡潔に。
6. タイマーはバックグラウンド耐性のため setInterval のカウントではなく Date.now() 基準で計算する。途中でリロードしても localStorage から進行中セッションを復元する。
