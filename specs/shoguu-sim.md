# アプリ1: 処遇改善加算 配分シミュレーター（放デイ・児発） slug=shoguu-sim OWNER=放デイの書類屋さん（houday.jp）
目的: 放課後等デイサービス／児童発達支援の経営者が、処遇改善加算の月額見込みと職員への配分案を作り、月額賃金改善要件を満たすかを即確認できる。
## 制度データ（令和8年6月1日〜の加算率。app.js内で定数化し、画面で編集可能＝告示改定に備える）
放課後等デイサービス: Ⅰ(イ)15.5% / Ⅰ(ロ)16.1% / Ⅱ(イ)15.2% / Ⅱ(ロ)15.8% / Ⅲ14.2% / Ⅳ11.9%
児童発達支援: Ⅰ(イ)15.2% / Ⅰ(ロ)15.8% / Ⅱ(イ)14.9% / Ⅱ(ロ)15.5% / Ⅲ13.9% / Ⅳ11.7%
要件:
- 月額賃金改善要件: 「加算Ⅳ相当額の1/2以上」を月額賃金（基本給・毎月の手当）で改善すること（全区分共通）。
- (ロ)区分の要件: 「加算Ⅱ(ロ)相当額の1/2以上」を月額賃金で配分、かつ 生産性向上の取組5つ以上（うち「現場課題の見える化」「業務支援ソフト導入」必須）または社会福祉連携推進法人所属。令和8年度は誓約で先行算定可だが実績報告で未実施なら返還。
- 加算額は全額を職員の賃金改善に充てる（配分合計 ≥ 加算額見込み）。対象は福祉・介護職員に限らず柔軟配分可（事業所の判断）。
- 加算対象額 = 月の総単位数×地域単価（円）ベースの報酬額（利用者負担分含む総額）。本ツールは「月間の対象報酬額（円）」を直接入力する方式＋補助として「総単位数×地域単価(10.00〜11.40円、初期10.00)」から計算する入力も用意。
## 画面
1. 条件入力カード: 事業所種別(放デイ/児発)、算定区分(6区分セレクト)、月間対象報酬額(円) or 総単位数＋地域単価、事業所名（任意）。加算率は「率を編集」トグルで6区分すべて上書き可（localStorageに保存、リセットボタン）。
2. KPIタイル: 月額加算見込み／年間見込み（×12）／月額賃金改善の必要額（Ⅳ相当×1/2）／(ロ)区分を狙う場合の必要月額（Ⅱ(ロ)相当×1/2）。
3. 職員配分表: 行=職員（氏名、職種セレクト: 児童指導員/保育士/児発管/管理者/その他）、月額改善額（円/月）、一時金・賞与（円/年）、年間改善額（自動=月額×12+一時金）。行追加/削除。Freeは5名まで、Proで無制限。
4. 判定カード: ①配分合計（年間） vs 加算見込み（年間）→ 不足なら ng・超過ならok（超過は持出額表示）、②月額配分合計 vs 月額賃金改善要件 → ok/ng、③(ロ)要件ライン達成か、④一人当たり平均改善額。ng時は具体的な不足額と「月額に○円回せば達成」の提案文。
5. 出力: 「配分表を印刷」（印刷用レイアウト＝事業所名・作成日・条件・表・判定）、「CSV出力」（Pro）、「保存/読込」（事業所を名前で複数保存＝Pro、Freeは1件自動保存）。
6. 注意書き .note: 率は令和8年6月改定版・自治体の告示で最終確認、対象報酬額の範囲（加算対象外の加算がある）は指定権者へ確認。
