# アプリ6: ゴールメーター（目標カウントダウン＋実行記録） slug=goal-meter OWNER=シャロッシング

目的: 日付のある目標（試験・転職・独立・資格更新・締切・体重など何でも）に対して、**続けることだけ**を支援する。計画は立つのに実行が続かない人、とくにADHD当事者を想定読者にする。既存の `sanshu-timer` が「本番当日の解き方」を訓練するのに対し、これは「本番までの350日を切らさない」ための道具。

## 設計思想（実装中に迷ったらここへ戻る。機能追加の圧力に対する防波堤）
- **表示する指標は3つだけ**。①次の締切までの残り日数 ②続いている日数 ③手応え（自己評価）の折れ線。指標を増やすと、記録をつけること自体が目標の代わりになる。達成率・週間グラフ・カテゴリ別集計は**作らない**。
- **主指標は「連続日数」ではなく「2日連続で欠けた回数」**。連続記録は途切れた瞬間に人を辞めさせる。1日休むのは計画の内、2日連続で初めて崩れる、という思想をUIで表現する。
- **中間目標は4つ目の指標ではない**。①の射程を短くするだけ。350日先の締切は行動を動かさないが、24日先は動かす。だから大きい数字は常に「次の締切まで」を出す。
- **計測と記録は1つの動作**。別操作にすると必ず片方を忘れる。計測を止めた瞬間に「今日やった」も立つ。
- **入力は全部任意**。空のまま「やった」を押せる。入力必須にすると、疲れている日に記録ごと飛ばす。記録が飛ぶ→連続が切れる→翌日の復帰が重くなる、の連鎖を止めるほうがデータの精度より優先。
- 通知・催促は作らない（通知で動くなら最初から困っていない）。ログイン・アカウントも作らない。

## データモデル（localStorage `hd_goal-meter_data`・JSON.parseはtry/catch）
```
{ goal: "簿記2級に合格", why: "転職の応募条件だから"|null, targetDate: "2027-06-13",
  milestones: [{ name:"テキスト1周", date:"2026-10-20" }],   // date昇順で保存
  session: { startedAt: "ISO8601" } | null,                   // 計測中のみ
  log: { "2026-09-09": { done:true, note:string|null, score:0..1|null, minutes:number } } }
```
- 既存の Scriptable 版ウィジェット（`~/Desktop/実行OS商品/GoalMeter.js`・iCloud Driveの `goal-meter.json`）と**同一スキーマ**。JSONの書き出し／読み込みで相互に移せるようにする。**自動同期はしない**（静的PWAのlocalStorageとiCloud Driveはサーバ無しでは繋がらない。できない約束をUIに書かないこと）。

## 計算ロジック（`node --check` 前に単体で確かめる）
- `daysLeft(date)`: 今日0時基準の日数差。負なら「+N日超過」と表示。
- `nextMilestone()`: 今日以降で最も近い中間目標。過ぎたものは自動で対象外＝**繰り上がりに手入れは不要**。無ければ最終目標を使う。
- `streak()`: 今日が未記録でも、昨日まで続いていれば連続は切らさない。「今日の分が終わっていない」と「途切れた」は別物として扱う。
- `doubleMisses()`: 直近90日で「2日連続で欠けた」回数。**記録開始日より前は数えない**（使い始めた瞬間に大量カウントされるのを防ぐ）。連鎖は1回に丸める。
- タイマー: `session.startedAt` を1つ持つだけ。経過は描画のたびに `Date.now()` から計算（`setInterval` のカウント加算にしない＝バックグラウンド耐性・リロード復元）。**360分を超えた計測は止め忘れとみなして破棄**し、その旨を伝える（寝ている間ずっとやったことにしない）。停止時は当日の `minutes` に加算し、`done:true` も同時に立てる。

## 画面
1. **初回セットアップ**: 「何のカウントダウン？」＝目標名／その日（`<input type=date>`）／なぜやるのか（任意）。日付が無いと残り日数という一番効く数字が出せない、と画面に書く。
2. **メイン（主画面・片手操作）**: 上に目標名と「最終まで N日 ・ 中間 d/N」。中央に**次の締切までの残り日数**を特大で。その下に `▸ 中間目標名 09/30`。右に連続日数（緑）または**「今日まだ」（朱・未記録時のみ色がつく唯一の場所）**と `2日欠 N`。下に手応えの折れ線（下記）。最下部に大きく **[▶ はじめる]／[■ おわる（NN分）]** と [今日の記録]。
   - 記録済みなら `why` を、未記録なら「最低ラインでいい。それも達成として記録する。」を1行出す。
3. **今日の記録**: ひとこと（任意）／手応え0〜100（任意）／[やった]／[記録を取り消す]。`minutes` は保持したまま上書きする（消さない）。
4. **中間目標**: 一覧（通過は ✓ とグレー、未来は ▸ と「あと N日」）＋追加・編集・削除。追加画面に「2〜6週間先くらいに置くのが効きます」と明記。
5. **履歴**: 日付／分数／手応え／ひとこと。JSON書き出し・読み込み（Scriptable版との受け渡し用）。

## 折れ線（Canvasで描画・外部ライブラリ禁止）
- 直近21件の `score`。**0〜1固定スケールにしない**（ほぼ直線になって傾きが読めない。実装済み版で実際に失敗した）。データの最小最大に±0.03の余白を付けて伸ばし、**基準線0.8は必ず範囲に含める**。
- 面を薄く塗る（線だけだと形が読めない）＋末尾の点を強調＋基準線は細いグレーの横線。
- 基準線の意味＝「下回り続けたら、やり方ではなく中身を見直す合図」。1回下回っただけでは何もしない旨をUIに書く。
