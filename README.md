# houday apps
放デイ・児発の経営者と社労士受験生向けの静的Webアプリ集（GitHub Pages）。ビルド不要・依存なし。

- `index.html` … カタログ
- `apps/<slug>/` … 各アプリ（index.html / app.js / app.css / manifest / sw / icons）
- `common/theme.css` … 共通テーマ、`common/license.js` … Pro解放（ライセンスキー・SHA-256照合）、`common/license-hashes.json` … キーのハッシュ一覧（平文キーはリポジトリ外で管理）
- `specs/` … 仕様書

公開URL: https://makotoikeda1977.github.io/houday-apps/
